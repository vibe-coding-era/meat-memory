# Default Projection

本目录保存仓库内的默认 Markdown projection 示例或默认 scope 内容。

## 当前内容

- `scopes/`：按 `scope_id` 组织的默认 Memory 文档投影

## 用途

- 为本地开发和默认演示数据提供参考结构

如果你关注的是存储实现本身，建议结合 [`../../crates/memory-store-md/`](../../crates/memory-store-md/) 和 [`../architecture/system-design.md`](../architecture/system-design.md) 一起看。
