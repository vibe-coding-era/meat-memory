# Runbook

本目录面向“把系统跑起来、验起来、排起来”的场景。

## 推荐入口

- [`usage-guide.md`](usage-guide.md)：完整使用说明，适合作为日常入口
- [`v2_1-quickstart.md`](v2_1-quickstart.md)：安装后快速配置、MCP 检查和 skill 导出
- [`local-deploy-v1.md`](local-deploy-v1.md)：本地 Docker Compose 部署
- [`cloud-deploy-v1.md`](cloud-deploy-v1.md)：云端部署骨架
- [`v1-acceptance.md`](v1-acceptance.md)：V1 验收标准与入口

## 什么时候看这里

- 需要从零启动一套环境
- 需要知道先跑哪个脚本
- 需要定位验收、健康检查或部署问题
