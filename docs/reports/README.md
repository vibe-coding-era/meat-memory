# Reports Index

本目录保存偏分析型、汇总型的文档报告，而不是测试运行产物。

## 当前内容

- `test-coverage-report.md`：工作区单元测试覆盖率分析、热点文件和产物位置说明

## 与 `tests/reports/` 的区别

- `docs/reports/`：偏静态分析报告、总结文档、适合人阅读
- `tests/reports/`：偏脚本生成的测试输出、latest/archive 归档结果

如果你要看最近一次测试运行结果，优先去 [`../../tests/reports/README.md`](../../tests/reports/README.md)。
