# V2.8 版本化 TaskList

状态：Accepted

更新时间：2026-04-24

## 1. V2.8 版本验收标准

- 进入新会话或新输入时，系统能稳定判断是否属于同一项目
- 明确重复写入可自动去重，但语义变化不会静默覆盖
- supersede / conflict / cross-project merge 会进入 proposal/review
- 用户可查看 versions、timeline、relations、audit 并执行 rollback / restore
- 用户可配置 distillation profile，并在写入前 preview 候选记忆
