# Tasks Index

本目录保存项目执行上下文，适合在进入实现前快速了解“项目做到哪了、下一步该做什么”。

## 文件说明

- `project-index.md`：项目现状索引，偏总览和仓库盘点
- `task-log.md`：按时间记录的执行日志、关键决策与下一步动作
- `tasklist.md`：版本化任务清单与验收边界

## 推荐阅读顺序

1. 先看 `project-index.md` 了解当前状态
2. 再看 `tasklist.md` 了解版本任务边界
3. 最后看 `task-log.md` 了解最近实际执行了什么

这些文档更偏内部执行上下文，不建议替代 [`../runbook/usage-guide.md`](../runbook/usage-guide.md) 作为对外使用说明。
