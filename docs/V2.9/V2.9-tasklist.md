# V2.9 版本化 TaskList

状态：Planning Draft

更新时间：2026-04-27

## 1. V2.9 版本验收标准

- 能运行至少一个 Meat Memory 自有 benchmark，并生成稳定报告。
- 能接入至少一个公开 benchmark suite，或在缺少数据集时给出清晰的跳过和准备说明。
- 召回链路能输出 `RecallTrace` 和面向用户的 `RecallExplanation`。
- Recall Budget Packer 能在固定 token budget 下解释 summary、full content、evidence 的取舍。
- Secret / PII Guard 能阻止或脱敏高风险内容的长期保存和召回。
- Health Report 能发现重复、冲突、过期、低置信度、高敏感和无人审阅记忆。
- Memory Passport 能导出和恢复指定 scope 的 portable bundle。
- CLI / HTTP / MCP / Browser Console 的 V2.9 主能力达到 surface parity。
- V2.9 acceptance、benchmark report、perf report、security report 能写入 `tests/reports/`。
- V2.7 / V2.8 核心入口兼容测试全部通过。
- Supermemory / mem0 / MemoryLake 的关键能力映射有 fixture 或 adapter skeleton 覆盖。
- V2.9 新增功能生产代码 line / function / region coverage 达到 100%。
