# V2.95 验收说明

## 验收目标

V2.95 验收确认三件事：

1. Supermemory、mem0、MemoryLake 的能力映射和 adapter fixture 可稳定生成。
2. benchmark、trace、health、passport、compat 在 CLI / HTTP / MCP 的核心只读语义一致。
3. V2.95 新增功能 targeted coverage gate 为 100%。

## 运行方式

```bash
./docs/scripts/v2_95-acceptance.sh
```

默认输出目录：

```text
tests/reports/compat/latest
```

## 验收项

| 验收项 | 命令 |
|---|---|
| 格式 | `cargo fmt --all --check` |
| 接口编译 | `cargo check -p memory-kernel -p memory-cli -p memory-http -p memory-mcp` |
| 竞品映射 / adapter fixture | `cargo test -p memory-kernel --lib v29_compat` |
| CLI compat report | `cargo test -p memory-cli --bin memory-cli compat` |
| HTTP V2.9 surface | `cargo test -p memory-http --lib v29` |
| MCP V2.9 surface | `cargo test -p memory-mcp --lib v29` |
| 三端 parity | `cargo test -p memory-cli --bin memory-cli surface_parity_smoke_covers_mcp_cli_and_http_contracts` |
| 报告生成 | `memory-cli compat report --json` |

## 通过标准

- `compatibility.json` 中 `schema_version` 为 `2.95`。
- `mappings` 覆盖 `Supermemory`、`mem0`、`MemoryLake`。
- `connector_skeletons` 覆盖 `local-git`、`markdown-docs`、`chat-export`。
- `adapter_drafts` 至少包含 3 个 fixture draft。
- `coverage_gate.new_feature_test_coverage_required` 为 `100%`。
- `coverage-v2_95-new-code.md` 生成并声明 V2.95 新增生产代码 targeted coverage gate 通过。
