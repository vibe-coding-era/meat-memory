# V2.93 Secret Guard 与 Health Report 验收说明

状态：Implemented

更新时间：2026-04-27

## 1. 验收标准

| 能力 | 标准 |
|---|---|
| secret detector | API key、Bearer token、private key、password、email、phone、private path 可分类 |
| ingest guard | API key 自动脱敏，private key 拒绝写入，password/private path 进入 review/proposal 语义 |
| recall guard | 未脱敏高风险 secret 不进入 search / trace context bundle |
| hard delete redaction | deleted 状态变更会清理高风险正文 |
| health report | 输出风险列表、风险等级、建议动作和 JSON / Markdown 投影 |
| observability | 输出 secret finding、blocked ingest、blocked recall、health report 指标 |
| 兼容回归 | 旧 remember/search/lifecycle report 入口保持可用，新字段追加不替换 |
| 覆盖率 | V2.93 新增生产代码 line / function / region 覆盖率口径为 100% |

## 2. 验收脚本

```bash
./docs/scripts/v2_93-acceptance.sh
```

脚本会写入：

```text
tests/reports/health/latest/
  health.json
  health.md
  health-report.json
  remember-redact.json
  remember-deny.log
  search-redacted.json
  coverage-v2_93-new-code.md
  v2_93-acceptance.txt
```

## 3. 关键断言

- `remember-redact.json` 不包含原始 `sk_test_...`，包含 `[REDACTED:API_KEY]`。
- private key 写入失败并返回 `write denied by secret guard`。
- `search-redacted.json` 不泄漏原始 API key。
- `health.md` 包含 `Memory Health Report` 和 `high_sensitivity`。
- `health-report.json` 包含至少 1 个 `secret_findings`、`restricted = 1` 和 high sensitivity risk。

## 4. 覆盖率说明

- domain security enum / struct / fingerprint 单测。
- kernel detector / ingest guard / recall guard / hard delete redaction / health analyzer / writer 单测。
- CLI health parser / output helper 单测。
- observability security metrics 单测。
- PG migration contract 单测。
- CLI smoke 覆盖真实 redact、deny、search、health report 投影。

## 5. 失败排查

| 失败点 | 排查方向 |
|---|---|
| API key 未脱敏 | 检查 detector assignment 规则和 `remember_artifact` guard 接入 |
| private key 未拒绝 | 检查 private key marker 检测和 denied action |
| search 泄漏原始 secret | 检查 ingest redaction 和 recall guard |
| health risk 缺失 | 检查 `analyze_memory_health` 风险分类和 report writer |
| migration contract 失败 | 检查 `0011` 是否被 `PgStore::migrate` 执行 |
