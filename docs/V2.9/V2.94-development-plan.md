# V2.94 Evidence 与 Memory Passport 开发方案

状态：Implemented

更新时间：2026-04-27

## 1. 目标

V2.94 把记忆变成可追溯、可验证、可迁移的资产：每条 memory 可以解释来源证据，指定 scope 可以导出 portable passport bundle，并能在本地验证 hash 后导入到目标 scope。

## 2. 范围

- 新增 `EvidenceSpan` 领域对象，统一表达 text、image region、audio segment、video segment。
- 新增 `MemoryPassportManifest`、object hash、redaction、encryption metadata 等 passport 领域对象。
- Kernel 提供 provenance query，基于 memory / artifact / source refs 派生 evidence spans。
- Kernel 提供 passport export / verify / import。
- Passport export 默认执行 sensitive redaction，避免导出 raw secret。
- CLI 新增 `memory-cli passport export`、`verify`、`import`、`provenance`。
- 新增 PG `0012` 迁移，为 `evidence_spans` 和 `memory_passport_exports` 预留 additive schema。
- Passport 报告写入 `tests/reports/passport/latest/`，包括 manifest、memories、evidence、passport bundle 和 Markdown manifest。

## 3. 兼容策略

- 旧 `remember` / `search` / `trace` / `health` 命令不变；passport 是新增入口。
- 旧 Markdown memory projection 格式继续可读；passport 写入独立报告目录，不改变 `MEMORY.md` 结构。
- PG 迁移只追加 `0012`，不回写旧表，不改变 V2.7 / V2.8 / V2.91 / V2.92 / V2.93 数据语义。
- Import 到不同 target scope 时生成新的 memory id，并保留 `passport://...` source ref 和 `published_from_scope_id`，避免静默覆盖源 scope。
- Verify 必须先通过 manifest / object hash 检查，import 才会执行。
- Encryption 在 V2.94 先以 manifest metadata 表达，实际加密实现留给后续生产门禁阶段。

## 5. 验收

`docs/scripts/v2_94-acceptance.sh` 覆盖：

- domain / kernel / CLI / PG migration 单测。
- CLI provenance 能返回 evidence spans。
- CLI export 能写入 `passport.json`、`manifest.json`、`memories.json`、`evidence.json`、`manifest.md`。
- Export 默认 redaction，不泄漏原始 secret。
- CLI verify 能校验 schema version、object count 和 bundle hash。
- CLI import 能把 bundle 导入目标 scope，并可被 search 找回。
- V2.94 新增生产代码 100% 覆盖率口径说明。

## 6. 后续边界

V2.94 不做完整音频 / 视频理解，不做真实加密，也不做竞品导入 adapter。V2.95 继续承接 Supermemory / mem0 / MemoryLake 兼容映射和 surface parity，V2.96 再统一生产门禁与 UI。
