# V2.94 Evidence 与 Memory Passport 验收说明

状态：Implemented

更新时间：2026-04-27

## 1. 验收标准

| 能力 | 标准 |
|---|---|
| evidence span | text / image / audio / video locator 有统一领域表达 |
| provenance query | 指定 memory 可返回 evidence spans 和 source refs |
| passport export | 指定 scope 可导出 portable bundle 和 Markdown manifest |
| passport verify | 校验 manifest hash、object hash、object count 和 schema version |
| passport import | 通过校验后可导入目标 scope，跨 scope 不静默覆盖源 memory id |
| redaction | 默认导出不泄漏原始 high-risk secret |
| storage compatibility | PG `0012` 为 additive migration，不改变旧表语义 |
| 覆盖率 | V2.94 新增生产代码 line / function / region 覆盖率口径为 100% |

## 2. 验收脚本

```bash
./docs/scripts/v2_94-acceptance.sh
```

脚本会写入：

```text
tests/reports/passport/latest/
  passport.json
  manifest.json
  memories.json
  evidence.json
  manifest.md
  passport-export.json
  passport-verify.json
  passport-import.json
  provenance.json
  passport-import-search.json
  coverage-v2_94-new-code.md
  v2_94-acceptance.txt
```

## 3. 关键断言

- `provenance.json` 包含 `evidence_spans` 和源文档引用。
- `manifest.md` 包含 `Memory Passport Manifest` 和 `bundle_hash`。
- passport 报告目录不包含原始 `v294_secret_password`。
- `passport-verify.json` 中 `valid = true` 且 `schema_version = 2.94`。
- `passport-import.json` 中 `verified = true`，并包含 memory id mapping。
- import 后的目标 scope 可以通过 search 找到导入记忆。

## 4. 覆盖率说明

- domain evidence / passport / id 单测。
- kernel evidence derivation / redaction / writer / verify / import 单测。
- CLI passport parser / output helper 单测。
- PG migration contract 单测。
- CLI smoke 覆盖 provenance、export、verify、import、redaction 和导入后 search。

## 5. 失败排查

| 失败点 | 排查方向 |
|---|---|
| provenance 缺 source ref | 检查 `derive_evidence_spans` 是否保留 memory source refs |
| verify 失败 | 检查 manifest objects 与 `memories.json` / `evidence.json` 是否一致 |
| import 后 search 不到 | 检查 target scope mapping 和 markdown projection 写入 |
| raw secret 泄漏 | 检查 passport export redaction 和 report 目录输出 |
| migration contract 失败 | 检查 `0012` 是否被 `PgStore::migrate` 执行 |
