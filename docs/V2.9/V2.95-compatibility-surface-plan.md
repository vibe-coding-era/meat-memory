# V2.95 竞品兼容与接入面收口方案

## 1. 版本目标

V2.95 负责把 V2.91-V2.94 已完成的 benchmark、recall trace、health、passport 能力收口到一致的 CLI / HTTP / MCP surface，同时给 Supermemory、mem0、MemoryLake 建立可测试的兼容映射和导入 adapter skeleton。

V2.95 不做竞品私有 API 克隆，不做 SaaS 同步，不在 Agent-facing MCP 里开放高风险写入动作。它交付的是本地优先、可验证、可逐步扩展的兼容基线。

## 2. 老版本兼容设计

| 兼容对象 | V2.95 策略 | 验证方式 |
|---|---|---|
| V2.7 lifecycle / governance | 保留旧 CLI、HTTP、MCP 名称和 payload，新增 V2.9 surface 不覆盖旧入口 | `surface_parity_smoke_covers_mcp_cli_and_http_contracts` |
| V2.8 proposal / timeline / rollback | 不改 proposal、timeline、rollback handler；V2.95 只增加只读 report surface | V2.8 既有测试继续跑在 workspace gate |
| Markdown memory projection | 旧 frontmatter + body 可继续被读取；V2.9 report projection 只追加到 `tests/reports/*` | `v29_compat` markdown compatibility fixture |
| Markdown project docs projection | evidence refs 作为可选增强，不要求旧投影具备新字段 | `compatibility.json` 中 `markdown_compatibility` |

## 3. 竞品功能兼容设计

| 竞品 | 对齐能力 | Meat Memory 映射 | V2.95 交付 |

| MemoryLake | conflict / version / audit | document conflicts、timeline、lifecycle audit | mapping + old-version compatibility contract |

## 4. 接入面收口

| 能力 | CLI | HTTP | MCP | 风险边界 |
|---|---|---|---|---|
| Benchmark report | `memory-cli benchmark report` | `GET /api/v1/benchmark/report` | `memory.benchmark.report` | 只读，不触发跑测 |
| Trace inspect | `memory-cli trace inspect` | `GET /api/v1/recall/traces/inspect` | `memory.trace.inspect` | 只读，按 trace id 校验 |
| Health report | `memory-cli health report` | `GET /api/v1/health/report` | `memory.health.report` | 只读，不自动修复 |
| Passport manifest | `memory-cli passport verify` | `GET /api/v1/passports/manifest` | `memory.passport.manifest` | 只 inspect / verify，不 import / export |
| Compat report | `memory-cli compat report` | `GET /api/v1/compat/report` | `memory.compat.report` | 只输出映射和 fixture draft |

## 5. Connector Skeleton

## 6. 新增功能测试覆盖率 100% 口径

V2.95 新增生产代码区域必须有 targeted tests 覆盖：

| 新增区域 | 覆盖测试 |
|---|---|
| capability mapping | `cargo test -p memory-kernel --lib v29_compat` |
| adapter fixture parsing | `cargo test -p memory-kernel --lib v29_compat` |
| compat report writer | `cargo test -p memory-kernel --lib v29_compat` |
| CLI compat report | `cargo test -p memory-cli --bin memory-cli compat` |
| HTTP V2.9 read-only surface | `cargo test -p memory-http --lib v29` |
| MCP V2.9 read-only surface | `cargo test -p memory-mcp --lib v29` |
| CLI / HTTP / MCP parity contract | `cargo test -p memory-cli --bin memory-cli surface_parity_smoke_covers_mcp_cli_and_http_contracts` |

验收脚本会生成 `tests/reports/compat/latest/coverage-v2_95-new-code.md`，明确记录 V2.95 新增功能 targeted coverage gate 为 100%。

## 7. 交付物

- Kernel: `v29_compat` mapping、adapter fixture、report writer。
- CLI: `memory-cli compat report`。
- HTTP: benchmark / trace / health / passport manifest / compat report 只读 routes。
- MCP: benchmark / trace / health / passport manifest / compat report 只读 tools。
- Docs: 本方案、验收说明、tasklist 状态更新。
- Reports: `tests/reports/compat/latest/compatibility.json`、`compatibility.md`、`coverage-v2_95-new-code.md`。
