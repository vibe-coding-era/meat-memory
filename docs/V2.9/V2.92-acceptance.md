# V2.92 Acceptance

## 1. 必须通过

| 验收项 | 标准 |
|---|---|
| traced search | `Kernel::search_context_with_trace` 生成 `trace_id` |
| explanation | explanation 能说明 selected、candidate、filtered、budget |
| budget pack | budget pack 能输出 used chars、items、trimmed items |
| CLI trace | `memory-cli trace latest` 生成 trace 报告，`trace inspect` 可按 trace id 读取 |
| benchmark association | benchmark case JSON 包含 `trace_id` |
| 兼容回归 | 旧 `search_context` 返回结构不变，V2.91 benchmark 测试继续通过 |
| 覆盖率 | V2.92 新增生产代码 line / function / region coverage 目标为 100% |

## 4. 覆盖率说明

V2.92 的 100% 覆盖率先以新增生产代码的直接测试覆盖为门禁：

- domain recall model 和 ID 有单测。
- kernel traced search、failure classifier、budget pack、report writer 有单测。
- CLI trace parser、report 读取、输出 helper 有单测。
- observability recall metrics 有单测。
- 新迁移文件由 PG storage contract test 引用校验。

后续 V2.96 汇总发布时，再把 V2.91 到 V2.96 的覆盖率报告统一纳入 `v2_9-coverage-threshold.py`。

## 5. 失败处理

| 失败 | 处理 |
|---|---|
| `candidate_count = 0` | 检查 query normalization 和检索输入 |
| `filtered_count` 异常 | 检查 lifecycle / sensitivity / scope guard |
| `trimmed_items` 异常 | 检查 `max_records` 和 `max_chars` |
| trace id 不匹配 | 检查 `trace inspect` 的 input dir 是否指向最新报告 |
