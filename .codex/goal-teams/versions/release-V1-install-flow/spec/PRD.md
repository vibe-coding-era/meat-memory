# PRD: release-V1 安装流程验收

## 背景

用户在部署时遇到 `.env.example` 和 `docs/scripts/dev-up.sh` 缺失问题，随后要求安装命令先做环境检测、补充安装环境，再安装并使用 TUI 配置。

## 用户故事

作为 release-V1 用户，我希望复制部署目录后可以运行一条明确的安装命令，脚本先告诉我环境是否满足，再安装二进制，并引导我完成本地配置。

## 功能需求

1. 安装器支持 `--check`。
2. 安装器支持 `--install-deps`，且默认不擅自修改系统环境。
3. 安装器支持 `--tui` 和 `--skip-tui`。
4. 安装器在无交互终端时自动跳过 TUI 并给出后续命令。
5. 部署 README 默认中文，并说明正确部署入口。

## 非功能需求

- 不包含源码。
- 不提交无关文件。
- 错误信息可解释，可区分脚本 bug 和 release asset 缺失。
